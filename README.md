# sunnyzhang.dev

A lightweight, static portfolio built with semantic HTML and CSS. It has no
JavaScript, build step, or application runtime.

## Local development

Serve the repository with any static file server, for example:

```sh
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

The production site is [sunnyzhang.dev](https://sunnyzhang.dev).
